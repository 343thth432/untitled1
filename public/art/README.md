# Картинки персонажей

Движок людей не рисует. Пока файла нет, в кадре стоит тёмный силуэт со
свечением — это осознанный запасной вариант, а не заглушка «на потом».

Чтобы поставить свою картинку, положи файл сюда и назови по id персонажа.
Ничего править в коде не нужно — игра подхватит файл сама.

```
public/art/heroes/<id>.webp   портрет героини на титульном экране
public/art/foes/<id>.webp     противник в дуэли
```

`.png` тоже подойдёт: если `.webp` не найден, движок пробует `.png`.

## Требования к файлу

- Прозрачный фон (силуэт вырезан), иначе вокруг будет прямоугольник.
- Персонаж стоит на нижней кромке кадра: движок ставит картинку «ногами»
  на пол зала.
- Вертикальная пропорция, примерно 2:3. Ширина 512–1024 достаточно.
- Тёмная сцена: картинка не подсвечивается движком, поэтому лучше брать
  изображение с собственным контровым светом.

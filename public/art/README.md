# Своя графика без правки кода

Движок рисует всё сам: оружие, тварей, обстановку. Но любую картинку
можно подменить — положить файл сюда с нужным именем, и игра подхватит
его при следующей загрузке. Если файла нет, остаётся нарисованный
движком запасной вариант.

```
public/art/weapons/<id>.png    лента кадров оружия в руках
public/art/heroes/<id>.webp    портрет на титульном экране
```

Для портрета `.png` тоже подойдёт: если `.webp` не найден, движок
пробует `.png`.

Тварей подменить файлом нельзя: у каждой восемь ракурсов и полтора
десятка кадров, и движок собирает их сам (`src/dungeon/foeArt.ts`).
Внешность задаётся палитрой и телосложением в `src/dungeon/foes.ts` —
новая тварь добавляется одной записью.

## Оружие

Кадры лежат одной горизонтальной лентой: сначала клетки самого ствола,
за ними — клетки вспышки выстрела. Все клетки одного размера, ствол
внутри клетки стоит на своём месте — так кадры не «плавают» при
анимации.

Рядом лежит `weapons.json`, он описывает ленту:

```json
"ssg": {
  "cw": 156, "ch": 74,      клетка в пикселях
  "ox": 97,  "oy": 126,     её левый верхний угол на экране 320x200
  "n": 8,                   клеток со стволом
  "flash": 2,               клеток со вспышкой после них
  "seq": [[0, 1], [0.14, 2], ...]   доля цикла выстрела -> номер клетки
}
```

`ox`/`oy` заданы в координатах экрана 320x200 — того самого, в котором
Doom рисует оружие. Игра ставит ленту от нижней кромки кадра и
растягивает целыми пикселями под ширину телефона, поэтому пропорции
сохраняются на любом экране.

Чтобы добавить свой ствол (например меч или топор, которых нет в
готовых наборах), положи `<id>.png` и допиши в `weapons.json` запись с
тем же `id`, что у оружия в `src/dungeon/weapon.ts`. Ленты для
двустволки, пулемёта и ракетницы собирает `node tools/fetch-weapons.mjs`
из спрайтов Freedoom — скрипт перезаписывает эти три файла и манифест
целиком, так что свои записи держи в отдельной копии или добавляй их
после запуска.

Требования: прозрачный фон, никакого сглаживания при масштабировании
(рисуй в целевом разрешении), нижняя кромка ленты = нижняя кромка
экрана.

## Портрет на титуле

- Прозрачный фон (силуэт вырезан), иначе вокруг будет прямоугольник.
- Персонаж стоит на нижней кромке кадра: движок ставит картинку
  «ногами» на пол зала.
- Вертикальная пропорция, примерно 2:3. Ширина 512–1024 достаточно.
- Сцена тёмная, картинка движком не подсвечивается — лучше брать
  изображение с собственным контровым светом.

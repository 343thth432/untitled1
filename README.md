# Эклипс: Дочери Затмения

Мобильная вертикальная **AFK-арена** в аниме-стилистике: кампания с авто-боями и ручными
ультимейтами, коллекция героинь, снаряжение, дерево навыков, бесконечная башня с драфтом
усилений и асинхронная PvP-арена.

Героини — **процедурные 3D-модели** на three.js: у каждой своя фигура, крой костюма, причёска
и личное оружие. Бой идёт в реальной 3D-сцене, карточки в интерфейсе — это отрисованные
«фотографии» тех же моделей.

Игра целиком клиентская: React + TypeScript + Vite, устанавливается как PWA, работает офлайн,
сохранение живёт в IndexedDB на устройстве. Интерфейс — светлая тема.

---

## Запуск

```bash
npm install
npm run dev        # локальный сервер разработки
npm run build      # сборка в dist/
npm run preview    # предпросмотр собранной версии
npm run typecheck  # проверка типов
npm run balance    # прогон боевого баланса (см. ниже)
```

Открывать удобнее в мобильном режиме браузера (например 390×844). На телефоне страницу можно
«Добавить на главный экран» — она запустится в полноэкранном портретном режиме без адресной строки.

## Что уже играется

| Режим | Что делает |
| --- | --- |
| **Поход** | 12 глав × 12 этапов, элита на 6-м и босс на 12-м этапе каждой главы |
| **Награды простоя** | Ресурсы копятся офлайн до 12 часов + 3 бесплатных «быстрых награды» в день |
| **Отряд** | 5 слотов, слева — первая линия, справа — тыл; авто-подбор состава |
| **Призыв** | Гача на кристаллы или свитки, ×1 и ×10, гаранты на легендарную и мифическую |
| **Героиня** | Уровень, возвышение по звёздам, дерево навыков, 6 слотов снаряжения |
| **Снаряжение** | 6 слотов, 4 редкости, 6 комплектов с бонусами 2/4, заточка до +15, разбор |
| **Башня Эха** | Бесконечные этажи без лечения между боями, драфт из трёх усилений после каждой победы |
| **Арена** | Асинхронный PvP по снимкам отрядов, очки рейтинга, билеты по таймеру, лавка Славы |

### Бой

- Детерминированный тик-движок: **10 тиков в секунду**, один и тот же seed всегда даёт один
  и тот же бой. Тот же код считает и живой бой, и мгновенный «пропуск».
- Скорость ×1 / ×2 / ×4, кнопка пропуска, полностью автоматический режим.
- **Ручные ультимейты**: когда шкала энергии заполнена, портрет внизу загорается — нажмите,
  чтобы применить ульту в нужный момент. Если не нажать, героиня применит её сама через 3.5 с,
  так что невнимательность не проигрывает бой.
- 5 фракций с контрами (Пламя → Лоза → Прилив → Пламя, Свет ↔ Тьма) и 6 ролей.
- Статусы: баффы, дебаффы, периодический урон, щиты, оглушение, очищение, воскрешение.

### Героини

18 персонажей: 4 мифических, 5 легендарных, 6 эпических, 3 редких. У каждой — базовый навык,
ультимейт и пассивка со своим триггером (крит, убийство, смерть союзницы, порог здоровья,
начало боя, периодический).

## 3D-модели

Каждая героиня собирается кодом из параметров `Appearance` — никаких внешних ассетов, вся
игра остаётся одним самодостаточным бандлом.

- **Тело** строится из вращённого профиля (`LatheGeometry`) и конусов-конечностей, пропорции
  задаёт параметр `figure` (рост, талия, грудь).
- **Лицо** рисуется в canvas и запекается прямо в текстуру головы — ровно в тот участок
  UV-развёртки, который смотрит вперёд. Большие аниме-глаза, брови и линия рта зависят от
  «настроения» героини; у поверженной глаза закрыты.
- **Причёски** — восемь силуэтов (каре, хвост, твинтейлы, коса, пучки, волнистые…), у каждой
  своя геометрия задних прядей и боковые локоны у лица.
- **Костюмы** — восемь кроев (`leotard`, `plate`, `slit`, `coat`, `sarashi`, `robe`,
  `harness`, `qipao`), собираемые из общих деталей: чашки, полосы, панельные юбки с разрезами,
  наплечники, портупеи, чулки с подвязками, плащ.
- **Оружие** — 14 видов, у каждой героини своё: катана, двуручник, лук, арбалет, посох,
  жезл, коса, глефа, копьё, молот, парные кинжалы, когти, парящий гримуар, чакрамы. Для
  каждого прописана поза рук и хват.
- **Шейдинг** — `MeshToonMaterial` с трёхступенчатой рампой, контровой свет цветом ауры и
  контуры-обводки на силуэтных мешах.

Анимация (`src/art/model/actor.ts`): дыхание, покачивание волос и плаща, замах при атаке,
подъём оружия при касте, отдача при получении урона, падение при смерти.

**Где что рисуется**

| Место | Как |
| --- | --- |
| Бой | `BattleStage` — одна 3D-сцена на 10 моделей, полоски HP проецируются поверх как DOM |
| Экран героини, призыв | `HeroStage` — живая модель, вращается пальцем |
| Списки и карточки | `usePortrait` — один скрытый рендерер делает PNG и кэширует его |

Чтобы заменить процедурные модели на импортированные GLTF, достаточно подменить
`buildCharacter` в `src/art/model/character.ts` — остальной код работает с `Actor`.

## Структура

```
src/
├── art/
│   ├── model/              процедурная 3D-модель: тело, лицо, оружие, тон-шейдинг, анимация
│   ├── BattleStage.tsx     боевая 3D-сцена
│   ├── HeroStage.tsx       одна модель с вращением пальцем
│   └── portraitCache.ts    офлайн-рендер портретов для интерфейса
├── game/
│   ├── types.ts            типы предметной области
│   ├── data/               героини, фракции, снаряжение, главы, дерево, баффы башни
│   ├── engine/             ГПСЧ, расчёт статов, боевой движок, прогрессия, сборка отрядов
│   └── state/              zustand-стор и слой сохранения (IndexedDB → localStorage)
├── ui/
│   ├── components/         общие элементы, аватар, карточка предмета, шторка, тосты
│   └── screens/            поход, отряд, призыв, башня, арена, героиня, бой
└── index.css               Tailwind + светлая тема
tools/balance.ts            прогон боевого баланса
```

Вся числовая настройка сосредоточена в `src/game/engine/progression.ts` (опыт, возвышение,
награды, шансы призыва) и `src/game/engine/units.ts` (сила врагов по этапам и этажам).

## Инструмент баланса

`npm run balance` прогоняет боевой движок без интерфейса и печатает винрейты для нескольких
профилей игрока: новичок со стартовым отрядом, «одетый» игрок и игрок без снаряжения — по
ключевым этапам кампании и этажам башни. Так любую правку чисел можно проверить за секунду.

Текущая целевая кривая:

- новичок уверенно проходит первые этапы, спотыкается об элиту 1-6;
- игрок без снаряжения упирается в босса 5-й главы — это сигнал заняться экипировкой;
- одетый игрок проходит кампанию, но боссы 5-й, 9-й и 10-й глав остаются напряжёнными;
- башня становится стеной примерно на 70-м этаже при максимальных вложениях.

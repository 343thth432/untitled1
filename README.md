# Дорога Затмения

Мобильная игра-подземелье в браузере: спуск от первого лица и карточные
дуэли. Вертикальный экран, ставится как PWA, работает без сети.

## Как это выглядит

Вид от первого лица собирается рейкастером: стены, пол и свод — настоящие
материалы с картами нормалей, свет факела считается попиксельно, поэтому
кладка выпуклая, а не залита плоским цветом. Дальше факела всё уходит в мглу.

Людей движок не изображает. Метки событий и противники — тёмные силуэты со
свечением; если положить картинку в `public/art`, она встанет вместо силуэта
(см. `public/art/README.md`).

## Как играть

Три этажа: Склеп, Катакомбы, Святилище Затмения. На каждом разбросаны залы
с событиями, у спуска стоит хранитель.

- стрелки внизу — поворот и шаг; тап по метке или по плану этажа в углу
  ведёт героиню туда самостоятельно;
- бой — карточная дуэль: три энергии за ход, блок сгорает в начале хода,
  намерения противника видны заранее;
- между боями: привал (лечение или улучшение карты), тайник, торговец,
  знамение с выбором;
- хранитель этажа открывает спуск. Победа — пройти все три этажа.

## Разработка

```
npm i
npm run dev      # http://localhost:5173
npm run build
npm run sim      # автопрогон баланса без интерфейса
```

Текстуры подземелья скачиваются отдельно и лежат в репозитории:

```
node tools/fetch-tex.mjs
```

## Устройство

```
src/dungeon/     рейкастер, карта этажа, ходьба, силуэты, дуэльная сцена
src/game/        правила: карты, дуэль, забег, реликвии, знамения, данные
src/ui/          экраны и интерфейс
src/art/scene/   тёмный фон с боке для титульного экрана
public/tex/      материалы стен и пола (CC0, ambientCG)
public/art/      сюда кладутся картинки персонажей
tools/           автопрогон баланса и загрузка текстур
```

# Дорога Затмения

Мобильный шутер-подземелье в браузере: спуск от первого лица, оружие в руках,
твари в темноте. Вертикальный экран, ставится как PWA, работает без сети.

## Как это выглядит

Кадр считается рейкастером в низком разрешении и растягивается без сглаживания —
отсюда крупный честный пиксель. Стены, пол и свод — настоящие материалы с
картами нормалей; свет факела в руке считается попиксельно, а настенные факелы,
жаровни и кристаллы светят как отдельные источники. Разрешение буфера само
подстраивается под скорость устройства.

Людей движок не изображает. Твари — тёмные силуэты с горящими глазами; если
положить картинку в `public/art`, она встанет вместо силуэта
(см. `public/art/README.md`). Оружие в руках — пиксельный спрайт с покачиванием
при ходьбе, отдачей и вспышкой.

## Как играть

Три яруса: Склеп, Катакомбы, Святилище Затмения. На каждом бродят твари,
разбросаны заряды, отвары и оружие, а спуск открывается, когда убит хранитель.

**Управление на телефоне:** левая половина экрана — стик движения (появляется
там, где положил палец), правая — поворот перетаскиванием, круг внизу справа —
огонь. На клавиатуре: W/S — вперёд-назад, A/D — поворот, Q/E — боком,
пробел — огонь.

Три оружия: рунная кулеврина (быстрая), тяжёлый арбалет (бьёт сильно и редко),
кадило Затмения (веер зарядов вблизи). Прицел помогает: на телефоне попадание
считается по углу, а не по пикселю.

## Разработка

```
npm i
npm run dev      # http://localhost:5173
npm run build
```

Текстуры подземелья скачиваются отдельно и лежат в репозитории:

```
node tools/fetch-tex.mjs
```

## Устройство

```
src/dungeon/     рейкастер, карта и обстановка этажа, движение, твари,
                 оружие, пиксельные спрайты, игровой экран
src/game/        забег, данные героинь и тварей, сохранение
src/ui/          экраны и интерфейс
src/art/scene/   тёмный фон с боке для титульного экрана
public/tex/      материалы стен и пола (CC0, ambientCG)
public/art/      сюда кладутся картинки персонажей
tools/           автопрогон баланса и загрузка текстур
```

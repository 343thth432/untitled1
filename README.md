# Дорога Затмения

Мобильный вертикальный **карточный рогалик-путешествие**. Ты идёшь по дороге
через туманный лес, дождевую степь и соляные равнины; встречи разрешаются
дуэлью на картах. Три перегона, у каждого свой хранитель. Здоровье не
восстанавливается само — только на привале.

Всё нарисовано кодом: и героини, и пейзаж. Внешних ассетов в игре нет вообще,
бандл целиком меньше 300 КБ.

---

## Запуск

```bash
npm install
npm run dev        # локальный сервер разработки
npm run build      # сборка в dist/
npm run sim        # автопрогон дороги: проверка баланса
npm run typecheck
```

Игра ставится как PWA: вертикальный экран, офлайн, сейв в IndexedDB.

## Как играет

**Дорога.** На каждом шаге впереди видно, что ждёт: тень, привал, находка,
торговец, знамение. Часто дорога раздваивается — выбираешь одну ветку, вторая
пропадает. Пейзаж прокручивается, пока идёшь.

**Дуэль.** Портретная раскладка: тень сверху, ты снизу, рука карт внизу.
Энергии 3 за ход, добор 5 карт, в конце хода рука уходит в сброс. Блок сгорает
в начале твоего хода — копить его нельзя. Противник заранее показывает
намерение: сколько ударит, сколько закроется, чем проклянёт.

**Статусы.** Сила и плавность усиливают атаку и защиту; надлом и слабость
ломают; ожог, кровь и исток тикают в конце хода; корни пропускают ход
противника; шипы возвращают урон; сосредоточение добавляет карту в добор.

**Стихии.** Пламя → Лоза → Прилив → Пламя, Свет ↔ Тьма. Продавливание даёт
+20% урона, обратная сторона — −10%.

**Рост.** За бой дают карту на выбор и искры. Элита и хранитель добавляют
реликвию. На привале — либо лечение, либо заточка одной карты. Торговец берёт
искры. Знамения — короткие выборы с последствиями.

## Как это нарисовано

Никаких спрайтов и моделей: и героини, и мир пишутся на canvas.

**Живопись** (`src/art/illustration/`)

- `soft.ts` — кисть: размытые пятна тени и света, затемнение по внутренней
  кромке вместо обводки, блики, подповерхностное свечение, контровой свет
  вычитанием сдвинутой копии, растворение части у сустава. Палитры кожи,
  ткани и металла.
- `head.ts` — голова по реальным пропорциям: череп, скулы, челюсть, глазницы.
  Глаз с волокнами радужки, лимбом, влажной линией нижнего века и слёзным
  бугорком; нос лепится тенью и бликом; губы с объёмом и фильтрумом; брови из
  отдельных волосков; волосы — пряди-веретёна с острыми кончиками.
- `body.ts` — фигура ~6.5 голов, разобранная на 13 частей. Объём конечности
  строится светом, полутоном, ядром тени и рефлексом; шея уходит за челюсть,
  бедро перекрывает колено, плечо растворяется в корпусе — стыков не видно.
- `weapon.ts` — 14 видов оружия: сталь с бликом и долом, обмотка рукояти.

**Мир** (`src/art/road.ts`)

Пейзаж собирается из слоёв, каждый пишется один раз в широкий тайл и потом
повторяется со своей скоростью: небо с ореолом светила и облачными полосами,
три дальние гряды с воздушной перспективой, средний план (ельник, травостой,
соляные столбы, силуэты домов), полотно дороги с колеями, щебнем, лужами и
длинными тенями, передний план. Сверху — дымка у горизонта, общий тон кадра и
виньетка. Погода живёт отдельным слоем: дождь, снег, пыльца, пыль.

**Оживление** (`src/art/rig.ts`)

Скелет с иерархией костей: таз — корень, корпус и ноги отдельно, голова и руки
— дети корпуса, волосы — ребёнок головы. Позы описаны ключевыми кадрами.

| Состояние | Что происходит |
| --- | --- |
| Покой | дыхание, покачивание, контрапост |
| Шаг | маятник ног и рук, покачивание корпуса |
| Атака | замах над плечом, рубящий удар с шагом вперёд |
| Каст | обе руки вверх, оружие остриём в небо, пульсация |
| Отдача | отброс назад, руки в стороны |
| Смерть | падение с поворотом и растворением |
| Победа | прыжок, оружие поднято |

Части рига рендерятся один раз в офскрин-канвасы и дальше только
трансформируются — сцена с двумя фигурами не пересчитывает рисунок каждый кадр.

## Баланс

`npm run sim` прогоняет забеги без интерфейса простым, но не глупым автоигроком
(держит блок под входящий урон, остальное вкладывает в атаку; на привале точит
карту, если здоровья хватает) и печатает долю побед по стихиям, средний
прогресс и то, кто чаще всего убивает.

Текущая цель — около 60% побед у автоигрока: внимательный человек проходит
дорогу чаще, невнимательный застревает на втором хранителе. Основные ручки:
`foeScale` в `engine/run.ts` (рост силы теней), запас здоровья героинь и
рисунок намерений хранителей в `data/foes.ts`.

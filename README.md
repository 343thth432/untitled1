# Дорога Затмения

Мобильный шутер-подземелье в браузере: спуск от первого лица, оружие в руках,
твари в темноте. Вертикальный экран, ставится как PWA, работает без сети.

## Как это выглядит

Кадр считается рейкастером в низком разрешении и растягивается без сглаживания —
отсюда крупный честный пиксель. Стены, пол и свод — настоящие материалы с
картами нормалей; свет факела в руке считается попиксельно, а настенные факелы,
жаровни и кристаллы светят как отдельные источники. Разрешение буфера само
подстраивается под скорость устройства.

Оружие в руках — готовые пиксельные ленты кадров: покачивание при ходьбе,
отдача, вспышка, полный цикл перезарядки двухстволки.

Твари — кошкодевочки, и рисует их движок сам. Фигура собирается из скелета:
поза задаёт стопы, кисти, наклон и оседание, а рисовальщик наращивает на это
тело. Поэтому у каждой есть всё, что положено твари в Doom — пять ракурсов
(остальные три отражением), шаг в четыре кадра, замах, кадр боли, смерть по
кадрам и разрыв в клочья от тяжёлого попадания. Внешность и повадки заданы
одной записью в `src/dungeon/foes.ts`, так что новая тварь добавляется без
единой картинки.

## Как играть

Три яруса: Склеп, Катакомбы, Святилище Затмения. На каждом бродят твари,
разбросаны заряды, отвары и оружие, а спуск открывается, когда убита хозяйка.

**Бестиарий.** Драная и Подворотня берут числом и рвут когтями, Ворожея
швыряет светящиеся шары издали, Тяжёлая держит удар и бьёт больно, Копейщица
кладёт залп из двух шаров, Хозяйка склепа — залп из трёх и когти в упор.
Спящая тварь просыпается, увидев тебя или услышав выстрел, и будит соседок.

**Управление на телефоне:** левая половина экрана — стик движения (появляется
там, где положил палец), правая — поворот перетаскиванием, круг внизу справа —
огонь. На клавиатуре: W/S — вперёд-назад, A/D — поворот, Q/E — боком,
пробел — огонь.

**Арсенал.** Клинок и топор — без боеприпасов, бьют по дуге перед собой
(топор медленнее, но кладёт с одного удара). Двухстволка — четырнадцать
картечин веером, перезаряжается со сломом ствола. Пулемёт — вращающийся блок
стволов, короткий откат, ест пули пачками. Ракетница — ракета летит и рвётся
по площади, своим же разрывом заденет и тебя, если стрелять в упор.
Переключение — кнопками под полосой здоровья или клавишами 1–5.

Прицел помогает: на телефоне попадание считается по углу, а не по пикселю.

## Разработка

```
npm i
npm run dev      # http://localhost:5173
npm run build
```

Текстуры подземелья скачиваются отдельно и лежат в репозитории:

```
node tools/fetch-tex.mjs
```

## Устройство

```
src/dungeon/     рейкастер, карта и обстановка этажа, движение, твари и их
                 спрайты, оружие, снаряды, игровой экран
src/game/        забег, данные героинь и тварей, сохранение
src/ui/          экраны и интерфейс
src/art/scene/   тёмный фон с боке для титульного экрана
public/tex/      материалы стен и пола (CC0, ambientCG)
public/art/      подменная графика: оружие, твари, портреты
tools/           автопрогон баланса, загрузка текстур и спрайтов оружия
```

## Лицензии

Текстуры — ambientCG, CC0 1.0. Перечень в `public/tex/CREDITS.txt`.

Спрайты оружия в руках — проект Freedoom, BSD 3-clause. Их собирает
`node tools/fetch-weapons.mjs`, текст лицензии лежит в
`public/art/weapons/CREDITS.txt`. Графику из WAD'ов Doom брать нельзя:
id Software открыли исходники движка, а не данные игры.

Меч и топор Freedoom не покрывает — они по-прежнему рисуются движком.
Как подставить свои спрайты, написано в `public/art/README.md`.
